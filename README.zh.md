# 兰台（LanTai）

[English](README.md) | [中文](README.zh.md)

Obsidian **桌面端**插件：在本地库与对象存储之间上传、本地化、下载笔记图片，并内置多套存储配置档。

## 名称

**兰台**（拼音 **Lántái**；产品拉丁拼写 **LanTai**）借自中国历史上收藏图籍与档案的典藏意象。

- **发音：** 普通话拼音 **Lántái**（两字均为阳平，第二声）。英语近似可读 *lahn-tye*，请勿按英文单词随意拼读，也勿读成 necktie 的 *tie*。
- **历史语义：** 汉代宫廷设有名为「兰台」的中央图籍与档案典藏之所（宫内石室藏书，御史中丞兼领，置兰台令史典校秘书，并有奉诏修史之例）。后世引申指宫廷文献府库、史官或相关职司；今常作档案保管机构与档案工作的雅称。
- **与本插件：** 笔记中的图片在本地库与对象存储之间往返、妥善存放与调取——呼应「典藏」之意，而非一次性图床工具。

## 要求

- 仅 **桌面端** Obsidian（`isDesktopOnly`）
- Obsidian **≥ 1.11.4**（密钥经 Secret Storage / `SecretComponent`）

## 快速开始

1. 打开 **设置 → LanTai → S3**。
2. 新建**存储配置档**，填写桶、**公网访问前缀**、区域/端点等，并通过 Secret Storage 绑定访问密钥。
3. 将该配置档设为**当前启用**。
4. 在 Markdown **编辑**视图（所见即所得 / 源码）中，对渲染出的图片右键 → **上传**，或使用命令面板 **Upload current image**。

## 核心概念

| 术语 | 含义 |
|------|------|
| **上传** | 将本地图片推到当前启用的存储配置档，成功后把笔记链接替换为远程 URL。 |
| **本地化** | 将远程图片收入库；若目标路径已存在则只替换链接，不再写入文件。 |
| **下载** | 通过系统「另存为」导出到**库外**路径；**不**改笔记链接，**不**写入 vault。 |
| **插件管辖附件路径** | 图片落盘的目录与文件名规则（含上传/本地化，以及粘贴/拖拽等图片新建）；非图片仍走 Obsidian 全局新建位置。勿与 `obsidian-custom-attachment-location` 等同类插件同时强改路径。 |
| **存储配置档** | 一套可命名的对象存储连接；上传始终使用**当前启用**的那一套。 |
| **公网访问前缀** | 写入笔记的链接为 `公网访问前缀 + 对象键`（第一版不把预签名 URL 写入笔记）。 |

## 主要功能

- **单张动作：** 上传、本地化、下载（右键菜单 + 命令）。
- **整篇批量：** 上传当前笔记全部本地图；本地化当前笔记全部远程图（下载仅单张）。
- **存储配置档：** AWS S3、Cloudflare R2、阿里云 OSS、腾讯云 COS、以及 S3 兼容自定义端点（如 MinIO）。
- **模板：** 本地路径模板与各配置档的对象键模板；命名变量白名单：`noteFileName`、`noteFolderName`、`noteFilePath`、`noteFolderPath`、`date`、`uuid`、`random`、`originalName`、`ext`。
- **链接风格：** 本地路径可选 Wiki / Markdown（默认 Wiki）；**远程 http(s) URL 一律 Markdown** `![](https://...)`。提供当前笔记内图片链接的 Wiki ↔ Markdown 转换命令。
- **上传后删源**（可选）：上传并替换链接成功后，将本地源文件移入 Obsidian 回收站。
- **S3 图库：** 侧边栏 Ribbon 浏览、搜索与管理对象。

## 触发方式

- **图片右键** — 仅 Markdown **编辑态**（所见即所得 / 源码有渲染图）。阅读/预览模式使用 Obsidian 原生菜单。
- **命令面板** — 单张上传 / 本地化 / 下载；整篇上传 / 本地化；链接风格转换。
- **设置 → LanTai** — General（附件基点、本地路径模板、链接风格）与 S3（配置档、当前启用、上传后删源）。
- **Ribbon** — 浏览 S3 图片。

## 限制

- 仅桌面端；第一版不含粘贴/拖拽**自动上传**（图片新建落盘仍走插件路径模板）。
- 无整篇批量「另存为」。
- 预览/阅读模式不接管图片菜单。
- 本地化/上传写入冲突时失败并提示（不覆盖、不加后缀）；图片**新建**同名则按 Obsidian 习惯去重（`name 1`）。
- 压缩、OCR、标注类工具尚未提供（相关设置占位已暂时隐藏）。
